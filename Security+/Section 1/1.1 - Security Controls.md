## Categories:
- Technical: 
	- Implemented by a technical system 
	- Example: Managing an OS by allowing/disallowing processes
	- Implementation of firewalls, antivirus
- Managerial:
	- Policies on best practices to manage a system 
	- Can be implemented as daily work procedure
- Operational
	- Use of human resource to set controls
- Physical
	- Limiting physical access
