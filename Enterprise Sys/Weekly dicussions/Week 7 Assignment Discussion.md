## Enterprise strategic enablers
- Strategic enterprise enablers are tools used to positively impact the way a business work
- This concerns all the data that is available in an organization with no ways for the end user to use them or without a proper data scientist 
- Methods:
	- Accessibility:
		- Devolving UX so that they no longer need specialized skills
		- This eliminates the need for specialist skills to deeply examine the data
		- The process can be simpler for the end user with a lower skill ceiling
		- Example: Simplified portal for employees for timesheet and leave requests
	- Integration:
		- promote the use of single system and eliminate the need for multiple system for simplicity sake
		- No longer worry about integration due to convolute system to access the same system
		- Prevents data being out of sync and being in multiple places
		- Example: Having separated HR and Financial system makes it hard to determine if you have the budget to promote someone, and having an integrated system make it easier for this process
	- Visualization:
		- How to visualize complex data in a simple way like a dashboard and without manipulating large dataset to know if the business is running well
		- Example: Dashboard of students who applied to a course within the last 3 weeks
	- Automation:
		- Pulling things from the system automatically overnight with syncing and without requiring manual review
		- Someone creating a report to check for outline cases and make an additional change to the system - process of creating records
		- How do you trigger a process - someone submit a form, a manager approves and the system triggers the creation process
		- Example: The use of publisher in the performance management team to pull values from the system without manual intervention
	- Codification:
		- The process of enforcing business rules into a structure format
		- Example: Following and validating business rules without having to referring to policy by simplifying approval and automated checks
