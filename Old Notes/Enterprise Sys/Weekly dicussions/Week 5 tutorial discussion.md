System design life cycle: the process of designing a software 
Process: planning > analysis > design > build > test > deploy > decommission > maintenance
Planning: 
	Understand the problem and find potential solution 
	Define the problem statement
Analysis:
	Understand how to build the solution
	Do research from past problems
Build:
	Build the actual solution for the problem 
	Conduct tests
Test:
	Acquire user testing to get more information about the solution
Deploy:
	Deploy the solution on a platform
Decommission:
	Stop active work on solution 
Maintenance:
	Provide support

Case for change:
	Why do we need to change this structure or system
Discovery:
	Identify the reason for the change
