## CIA Triad
- Confidentiality - Integrity - Availability > Foundation of IT systems
- Confidentiality:
	- How to make sure the right recipient receive the message
	- Use of encryption, access controls, etc.
- Integrity:
	- Ensuring that the data received is not tampered with
	- Use hash value to compare results, digital signature to verify senders and digital certificates
	- Follow non-repudiation: proof of integrity to be genuine
- Availability:
	- How to make information accessible at all time
	- Build systems with redundancy and fault tolerance

## Non-repudiation:
- Ensuring that the data received comes from a genuine sender
- Can be done with 2 methods:
	- Proof of integrity
	- Proof of origin, with high assurance of authenticity
- **Proof of integrity**:
	- Verify that the received data is the same as the data sent
	- Use of hashing - strings of text generated from the data contained in the plain text
	- If the data changes then the hash changes
	- Can only be used to verify the integrity of the data itself and not the sender
- **Proof of origin**:
	- The use of hash provides proof of integrity
	- Verify the person that sent the data by using a digital signature to provide non-repudiation
	- This ensure that the sender is genuine
	- Cryptography uses digital signature:
		- Use a private key known only to the relevant parties
		- Use the public key to verify that the sender have the correct signature
