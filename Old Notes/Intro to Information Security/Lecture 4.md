## IS models
- Provides a foundation to IS models and an outline for IS controls
- May extend into specification of management processes needed for implementation of infosec control
- Some models originated as normative models for information security evaluation or as simple checklist

## Relevant security models
- Primary - ISO 27000 series
	- "Information technology - Security techniques - Information security management system" or ISMS
	- ISO 27002 (or AS 27002) 'Code of practice for information security management' - normative model for infosec control
	- ISO 27001 'Requirements' - provides specifications for an appropriate management system for IS
- Of interest - AusGOV - Protective Security Policy Framework (PSPF) and Information Security Manual (ISM)
